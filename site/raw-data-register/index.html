02

Install in three steps

  1. Choose the correct platform.Download the Mac DMG or open the official Windows product in Microsoft Store. Keep both options visible when helping another lab member.
  2. Verify the distribution source.macOS should identify the notarized Developer ID app. On Windows, confirm Store ID 9NTVDFKS4T1C and publisher leventb.
  3. Open the application.Configure the instrument once. Registration, hashing, and export continue to work without Internet access.

03

Installer integrity

The Mac installer checksum confirms the downloaded DMG; Windows package integrity is enforced by Microsoft Store signing. Both are separate from the SHA-256 fingerprints that Raw Data Register creates for research files, and neither makes a scientific claim about raw data.
